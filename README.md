# 🤖 Self Bot - سیستم سلف‌بات چندکاربره تلگرام

یک سیستم پیشرفته سلف‌بات برای تلگرام با قابلیت مدیریت چندین اکانت به صورت همزمان، بدون مشکل `database is locked`.

## ✨ ویژگی‌ها

- 🎛 **پنل کنترل اینلاین**: با دستور `.پنل` در هر چتی
- ⏰ **ساعت پروفایل**: با 13 فونت Unicode مختلف
- 📢 **تبلیغات خودکار**: ارسال بنر به گروه‌ها با حالت فوروارد/عادی
- ⚔️ **مدیریت دشمن**: پاسخ خودکار به دشمنان
- 🤫 **سکوت خودکار**: حذف پیام‌های کاربران خاص
- 📨 **اسپم پیام**: ارسال پیام تکراری
- 🗑 **حذف پیام**: حذف گروهی پیام‌های ارسالی
- 🕐 **منطقه زمانی تهران**: همه زمان‌ها بر اساس افق تهران
- 💾 **StringSession**: بدون مشکل قفل دیتابیس
- 📊 **گزارش‌دهی**: ارسال آمار تبلیغات در Saved Messages
